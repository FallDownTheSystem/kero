# 助手

助手是你的一个不属于任何项目的智能体：它有名称、颜色和头像、角色、它做什么或跟踪什么，以及 Kero 唤醒它进行的检查。一个助手可以每天早上跟进你的 Jira 工单，另一个读你的邮件，再一个每周一清理已合并的分支，或提醒你还没回答的问题。助手没有自己的工具：它们使用你的机器提供给智能体的东西，即 MCP 服务器、命令行工具和技能。

## 助手视图

会话侧边栏顶部的切换开关在 **会话** 和 **助手** 之间切换（**视图 › 会话或助手**）。有助手需要你时，助手一栏会显示圆点和数量；有未读消息时显示绿色圆点。

视图按助手的 **分组** 归类，没有分组的排在前面。每一行显示头像、名称及其会话的状态，第二行显示其状态行，没有时显示最后一份报告的第一行，再没有时显示角色；右侧显示下次检查的时间、**已暂停** 或出现的问题。助手启动的会话显示在它下方。

点击助手会像其他会话一样在窗口中显示它的会话；没有会话时会先启动一个。用 **+** 或 **会话 › 新建助手…** 添加助手。右键点击助手可使用 **立即运行检查**、**新聊天**、**暂停检查**、**编辑…**、**显示文件夹**、**关闭会话** 和 **删除助手…**。会话视图不列出助手的会话，但会在各自的项目中列出助手启动的会话。

## 创建助手

对话框会询问 **名称**、**角色**（一行，如“推进我的 Jira 工单”）、**颜色**（八种之一，或在其后的取色器中选的任意颜色）、**头像**（首字母、二十个图标之一（九个符号和十一种动物），或你自己的 2 MB 以内的 PNG、JPEG、GIF 或 WebP 图片）、它做什么或跟踪什么、**分组**、**检查**，以及 **代理** 和 **参数**。创建后，其会话会启动并显示，以便你回答智能体最初的问题，例如是否信任它的文件夹。

检查在无人值守时运行：请求权限的智能体会等待你。请为它提供允许检查所需操作的参数，例如 Claude Code 的 `--allowedTools` 或 `--permission-mode`。

## 检查

检查可以是在某个时间的 **每天**、在某几天某个时间的 **每周**，或 **Kero 启动时**，每个检查都有要检查的内容。检查仅在此电脑上的 Kero 运行时，按本地时间进行。Kero 会记录每个检查的运行时间：在 Kero 关闭或电脑关机期间错过的检查，无论错过多少次，都会在 Kero 下次运行时运行一次。**Kero 启动时** 的检查在每次 kerod 启动时运行一次，但最多每四小时一次，这样为更新而重启时不会重复运行。如果将 kerod 安装为服务（`kero daemon install-service`），即使关闭 Kero 的窗口，检查也会运行。

检查会在助手的智能体回到提示符时，以“Kero: message from your schedule:”送达，附带到期的检查及各自的到期时间；忙碌的助手会在本回合结束后收到。助手没有会话时，Kero 会先启动它的会话。

## 报告和通知

助手在每次检查结束时，用 `kero assistants report` 以 Kero 中所有智能体报告的四个部分（Result、Not done、Where、Next）进行报告。Kero 保留最近十份。以“Waiting on you:”开头的报告会让助手显示为等待这个问题（计入“需要你”），直到你在它的会话中回答或它再次报告。

Kero 会按照 **通知** 设置，在助手需要你或失败时，以及完成一次检查时通知你：标题为“Jira 完成了一次检查”，内容为报告的结果。它的其他回合（例如回复它启动的会话）只会标记为未读。

## 它的文件夹

每个助手在 Kero 配置文件旁的 `assistants/<id>` 中有一个文件夹，包含：

- `CLAUDE.md` 和 `AGENTS.md`：它的指示，Kero 根据其角色、跟踪的内容和检查写入，并在你编辑时重写。
- `USER.md`：你自己给它的指示，Kero 只创建一次，之后从不修改。
- `MEMORY.md`：它在检查和聊天之间保留的笔记，Kero 从不修改。

它的会话在这个文件夹中运行，其窗格会获得值为其 id 的 `KERO_ASSISTANT`。删除助手时，除非你一并删除，否则文件夹会保留。

## 它启动的会话

对于仓库中的工作或耗时较长的工作，助手会用 `kero new` 并指定项目或文件夹来启动会话，该会话成为它的子会话：它像[编排器](./orchestrators.md)一样得知子会话的情况，并用 `kero message` 给它发消息。子会话是否通知你由 **编排器的会话**（设置 › 通知）决定，其数量受 `orchestrator-max-children` 限制。

## 在命令行中

```sh
kero assistants                         # 每个助手的状态和下次检查
kero assistants news --json             # 各自最后的报告，以及谁在等你
kero assistants create Jira --role "Keeps my Jira tickets moving" \
    --check 'daily@09:00=What moved in my tickets since yesterday?'
kero assistants run jira                # 立即运行它的检查
kero assistants pause jira
```

`kero assistants help` 列出全部命令。[Ama](./ama.md) 会根据 `kero assistants news` 回答“我的助手有什么消息吗？”。
