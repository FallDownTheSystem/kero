# Ama

Ama 是替你操作 Kero 的智能体，名字来自日本树蛙（雨蛙，*amagaeru*）。点击会话边栏底部的青蛙，或按 **Ctrl+Shift+A**（macOS 上为 **⇧⌘A**），或选择**显示 › Ama**，然后这样请它：

- “为项目 X 中每个打开的 PR 启动代码评审。”
- “清理所有旧的工作树。”
- “为这个文件夹添加新项目，并用这个目标在那里启动一个编排器。”
- “哪些会话需要我？”
- “关闭项目 Y 中所有已完成的会话。”
- “怎样在新工作树中运行设置脚本？”

Ama 是在真实终端中运行的普通智能体会话。它运行你的默认智能体，或你在**设置 › 智能体 › Ama** 中选择的智能体（`ama-agent`）。它自己不做项目工作：真正的工作，它会在合适的项目中启动会话或[编排器](./orchestrators.md)。它不属于任何项目，并且只有一个 Ama。边栏不列出它，“需要你”不计入它，它也不发通知。Ama 等待你时，青蛙上会显示一个圆点。

Ama 用[管理 Kero](./cli.md#managing-kero) 中的命令管理 Kero，并在执行无法撤销的操作前先询问，比如关闭正在工作的会话，或删除有改动的工作树。

## 它的窗口

Ama 在 Kero 窗口之上的独立窗口中打开。拖动它的标题栏可以移动它（也可以移到另一台显示器上），拖动边缘可以调整大小。Kero 会记住它的大小，以及它相对于 Kero 窗口的位置：移动或调整 Kero 窗口时它会跟着走；Kero 窗口靠近屏幕边缘或某台显示器被移除时，它会留在显示器内。大小和位置以 DIP 保存，所以在缩放比例不同的显示器之间它保持同样大小。关闭窗口后 Ama 继续运行，下次打开时仍是同一对话。在标题栏中：

- **新对话**开始一段新对话。
- **历史**回到 Ama 之前的某段对话。
- **清屏**清除屏幕。

要让窗口以最初的大小回到青蛙上方，右键点击青蛙并选择**重置窗口位置**，或在**设置 › 智能体 › Ama** 中点击**重置**。

Ama 的文字比终端小 1 磅（**设置 › 智能体 › Ama** 中的**文字大小**，`ama-font-size`；`0` 为自动）。Ama 的窗口中隐藏 Claude Code 的状态栏（`ama-hide-status-line`，默认开启）：Kero 在 Ama 文件夹的 `.claude/settings.json` 中写入一个空的状态栏，不改动你自己的 Claude Code 设置。Claude Code 没有能在不关闭钩子的情况下彻底去掉状态栏的设置，所以原处会留下一行空行。如果该文件中已有你自己的状态栏，Kero 不会改动它；旁边的 `.claude/settings.local.json` 优先于二者。

<a id="its-folder"></a>

## 它的文件夹

Ama 在 Kero 配置文件旁的专属文件夹 `ama` 中运行（`~/.config/kero/ama`，或以 `kero config path` 所示为准）。Kero 会在 Ama 启动前写入它：

| 文件 | 内容 |
| --- | --- |
| `CLAUDE.md`、`AGENTS.md` | Ama 的指示：它的角色提示词和 Kero 文档的列表。Kero 更新时、以及你修改角色提示词时，Kero 会重写它们 |
| `USER.md` | 你自己给 Ama 的指示，Kero 只创建一次，之后从不修改 |
| `docs/` | Kero 的文档，即这些页面，为当前版本的 Kero 所附带的那一份。Kero 更新时会重写它们 |
| `.claude/settings.json` | `ama-hide-status-line` 开启时写入的空状态栏 |

## Ama 知道什么

Ama 从三个地方了解 Kero：

- **它的角色提示词**，在 `CLAUDE.md` 和 `AGENTS.md` 中：它的用途、它运行的命令，以及它的规则。
- **Kero 的文档**，在它文件夹的 `docs/` 中，即你所用版本的 Kero 附带的本站页面（英文）。它的指示列出了每个页面及其内容，并要求 Ama 在回答问题前先阅读相关页面，而不是猜测或去搜索 Kero 的程序。
- **Kero 的技能**：Ama 启动前，Kero 会像 `kero skill setup` 那样为 Ama 的智能体安装它；还有 `kero help`：所有命令和选项。

因此，Ama 会根据你所运行版本的文档回答关于 Kero 的问题，比如某个设置如何工作、某个按钮在哪里。

## 你的指示

Kero 把 Ama 的指示写入它的文件夹，作为 `CLAUDE.md` 和 `AGENTS.md`，并在 Kero 更新时重写。内容是 Kero 给 Ama 的角色提示词，可在**设置 › 智能体 › Ama › 角色提示词**（`ama-prompt`）中替换；**恢复默认**会还原 Kero 的版本。Ama 的智能体从下一次对话起读取它。你自己的提示词只替换 Kero 的角色提示词：文档列表仍会跟在它后面。

在角色提示词之外，你自己的指示写在旁边的 `USER.md` 中，比如评审时启动哪个智能体、你用简称指代哪些项目，或关闭之前要问你什么。Kero 只创建一次该文件，之后从不修改，Ama 会先读它。可从**设置 › 智能体 › Ama** 打开。

**参数**（`ama-agent-args`）加在 Ama 的智能体命令之后，例如 `--model sonnet`，因此不必为 Ama 另加一个智能体：Ama 启动和恢复时，Kero 都会加上它们。

<a id="without-remote-control"></a>

## 无需远程控制

Ama 不需要[远程控制](./agents.md#remote-control)：kerod 只给 Ama 的窗格一个秘密值 `$KERO_AMA`，即用 kerod 每次启动时重新生成的密钥对 Ama 的会话做的哈希。`kero do`、`kero focus` 和 `kero browser` 会传递它，只有 kerod 确认它属于 Ama 时，应用才会在没有远程控制的情况下执行操作。它不存入任何文件，其他窗格拿不到，对其他机器的 kerod 也无意义，所以其他智能体仍由远程控制设置决定。
