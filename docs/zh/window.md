# 窗口

Kero 的窗口从左到右分为三部分：**会话边栏**、你所在会话的**窗格**，以及**右侧边栏**；右侧边栏显示文件或拉取请求时，旁边还有**查看器**。设置 `sessions-sidebar = right` 时，会话边栏位于右侧，右侧边栏和查看器位于左侧。

## 会话边栏

会话边栏列出你的[项目](./sessions.md#projects)，每个项目下方是它的会话。用**切换边栏**（<kbd>⌘</kbd> <kbd>B</kbd>，Windows 和 Linux 上为 <kbd>Ctrl</kbd> <kbd>Shift</kbd> <kbd>B</kbd>）显示或隐藏它。

- **项目的标题**显示它的名称、它包含的会话数量（`sidebar-session-count`），以及打开[新建会话对话框](./sessions.md#new-session-dialog)的 **+**。它的菜单可以启动会话、在工作树中启动会话、移动项目，以及删除项目。拖动标题可以调整项目的顺序。
- **会话的行**显示它的状态图标和名称；设置 `sidebar-rows = detailed` 时，第二行显示它的状态消息，没有时显示它的分支和改动。在自己的分支上工作的会话（比如在[工作树](./worktrees.md)中）会显示分支的名称。[编排器](./orchestrators.md)带有标记，它的子会话显示在它下方，每个前面有 ↳；审查拉取请求的会话标为**审查**。将鼠标悬停在会话上，可以看到它的分支、相对上游领先或落后多少，以及它的拉取请求的检查状态。它的菜单（右键点击）可以重命名会话、在退出后重启它、标为已读、移到另一个项目、复制它的 id 或文件夹、在文件管理器中显示它的文件夹、显示或取消链接它的拉取请求、把它设为编排器，以及关闭它。
- 开启 `session-history` 时，**已结束**和**已归档**会列出智能体已结束的对话，以便恢复（[过去的对话](./sessions.md#past-conversations)）。

在它的底部：

- **打开项目**、**前往会话**（[命令面板](./shortcuts.md#the-command-palette)）、**设置**，以及**菜单**（⋯）：在没有菜单栏的 Windows 和 Linux 上，菜单栏的菜单都在这里。
- 右侧是需要你的会话、正在工作的会话，以及已完成但你还没看过的会话的数量；点击其中一个，会跳到下一个这样的会话。无法连接 kerod 时，底部会改为显示**正在连接…**或**无法连接 kerod**（[故障排除](./troubleshooting.md#restarting-kerod)）。
- Kero 更新后、kerod 仍在运行旧版本时出现的重启按钮：它会重启后台服务，你的会话也随之在原处重新启动。
- 青蛙，用来打开 [Ama](./ama.md)。Ama 等待你时，它会显示一个圆点；它的菜单中有**重置窗口位置**。

## 窗格

窗口中间是你所在的会话：它的[窗格](./panes.md)，包括终端、编辑器窗格和浏览器窗格，左右并排或上下排列。每个窗格的标题会显示它的文件夹（`pane-folder`），以及它的分支和改动增加、删除的行数，如 `fix-login +40 −2`。点击窗格的分支可以显示它的[改动](./changes.md)。你不在其中的窗格会淡化（`dim-unfocused-terminals`）。

## 右侧边栏

右侧边栏有四个标签页：

| 标签页 | 显示 | 页面 |
| --- | --- | --- |
| **文件** | 窗格工作树中的文件，以及搜索其文本的**搜索** | [文件与搜索](./files.md) |
| **改动** | 改了什么，按上一轮、未提交或分支；暂存与提交、分支与储藏 | [改动](./changes.md#changes) |
| **历史** | 以图的形式显示的提交、储藏、仓库的工作树 | [改动](./changes.md#history) |
| **审查** | 仓库中打开的拉取请求，以及审查它们的智能体 | [拉取请求](./pull-requests.md) |

点击窗口右上角的按钮可以显示或隐藏它，也可以用快捷键打开某个标签页（[键盘快捷键](./shortcuts.md#view)）。拖动它的边缘可以调整宽度；隐藏按钮旁的**放大侧边栏**会让它占据窗格的空间，点击**显示所有窗格**即可恢复。窗口太窄、放不下它和窗格时，它会自动让开，窗口变宽后再回来。

## 查看器

在文件、改动或搜索中点击的文件，以及在审查中点击的拉取请求，会在查看器（窗格旁边的卡片）中打开：可以阅读和编辑的文件、它的 diff，或拉取请求的页面。点击 <kbd>×</kbd> 关闭它，或按 <kbd>Esc</kbd> 离开它。**放大查看器**会让它占据窗格的空间，**在窗格中打开**会把文件移到单独的编辑器窗格中。

## 卡片与通知

- 右下角的卡片会显示每个新工作树的[设置](./worktrees.md#where-worktrees-go-and-what-they-start-from)进度，并提供**取消**。
- 简短的消息（比如某个操作的错误）会在窗口上方短暂显示。
- [通知](./status.md#notifications)是系统的通知：会话需要你、智能体完成、程序失败，或拉取请求请求你审查时发出。

## Ama 的窗口

[Ama](./ama.md) 在 Kero 窗口之上的独立窗口中打开，可以从青蛙打开，或按 <kbd>Ctrl</kbd> <kbd>Shift</kbd> <kbd>A</kbd>（macOS 上为 <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>A</kbd>）。它的标题栏中有**新对话**、**历史**和**清屏**。

## Kero 的图标

Kero 在 Windows 和 Linux 的通知区域、以及 macOS 菜单栏（`macos-show-app-icon`）中的图标，会在你关闭窗口后让 Kero 继续运行。它的菜单可以打开 Kero、打开[快速终端](./shortcuts.md#quick-terminal)、让电脑保持唤醒（`keep-computer-awake`）、打开设置、检查更新，以及退出：**退出**会让会话继续在 kerod 中运行，**退出并结束所有会话…**则会结束它们。

## 设置

**设置…**（<kbd>⌘</kbd> <kbd>,</kbd>，<kbd>Ctrl</kbd> <kbd>,</kbd>）会打开设置窗口，其中的搜索框可以按名称或配置项查找设置。每个页面写入的都是[配置](./configuration.md)中的配置项：

| 页面 | 设置内容 |
| --- | --- |
| **通用** | 新会话在哪里启动、如何命名，侧边栏的行，关闭和恢复会话，登录时打开 Kero，让电脑保持唤醒，更新 |
| **外观** | 浅色或深色、语言、主题及其颜色、应用的字体、会话边栏位于哪一侧、淡化你不在其中的部分 |
| **终端** | 终端的字体及其大小、粗细和特性，行高，光标，复制和鼠标 |
| **文件** | 你的编辑器、文件标签页中的点文件、代码的颜色 |
| **Git** | Git 状态、diff、分支切换器、工作树及其[清理](./worktrees.md#cleaning-up-worktrees)、提交信息、拉取请求：通知、关注、提示词 |
| **Shell** | 新窗格的 shell、它的环境、保留的回滚缓冲 |
| **浏览器** | 拦截广告、DevTools 端口 |
| **通知** | 什么会通知你、提示音、Dock 徽标 |
| **键盘** | 所有快捷键，可重新绑定 |
| **智能体** | 给智能体的 Kero 技能、各智能体和默认智能体、[编排器](./orchestrators.md)、[Ama](./ama.md)、恢复命令、远程控制 |
| **主机** | [远程主机](./remote.md)，以及允许其他机器连接本机 |
| **高级** | 配置文件、后台服务（**重启**）、日志、数据文件夹、**重置所有设置** |
