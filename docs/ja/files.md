# ファイルと検索

右サイドバーの**ファイル**タブと**検索**は、今いるペインのワークツリー、リポジトリの外ならそのフォルダのファイルを表示します。リモートホストでは、そのホストのファイルです。サイドバーの表示、幅の変更、拡大については[右サイドバー](./changes.md#the-right-sidebar)を参照してください。

## ファイル

**ファイル**タブ、または <kbd>⌥</kbd> <kbd>⌘</kbd> <kbd>E</kbd>（Windows と Linux では <kbd>Ctrl</kbd> <kbd>Shift</kbd> <kbd>E</kbd>）で、ワークツリーのファイルをツリーで表示します。git が無視するものは薄く表示され、`.git` は表示されません。ドットファイルは `files-hidden` をオフにしない限り表示されます。

フォルダをクリックすると展開し、ファイルをクリックするとペインの横のビューアで開きます。キーでも移動できます：<kbd>↑</kbd> と <kbd>↓</kbd> で移動し、<kbd>→</kbd> と <kbd>←</kbd> でフォルダを開閉し、<kbd>Return</kbd>（<kbd>Enter</kbd>）でファイルを開き、<kbd>⌘</kbd> <kbd>↩</kbd>（<kbd>Ctrl</kbd> <kbd>Enter</kbd>）でエディタペインに開きます。ファイルはビューアに言語に合わせてハイライトされて開き、検索（<kbd>⌘</kbd> <kbd>F</kbd>）や編集ができます。読んでいる間もファイルの変更に追従します。ビューアに表示するファイルは一度に 1 つで、別のファイルを開くときは先に変更を保存するか確認されます。ボタンで文字を小さく・大きくしたり、長い行を折り返したりでき、Markdown ファイルでは **Markdown をプレビュー** で表示どおりに見られます。画像は画像として表示され、バイナリファイルと 4 MB を超えるファイルは開きません。**エディタで開く** でエディタに、**ペインで開く** で[エディタペイン](./panes.md#editor-panes)に開き、ターミナルの隣に置いておけます。

ツリーの上のボタンで、最上位に新しいファイルやフォルダを作ったり、ファイルのテキストを検索したり、ツリーを更新したり、フォルダを折りたたんだりできます。ファイルやフォルダのメニュー（右クリック）では、そのフォルダに作成したり、名前を変更したり、削除したりできます。表示される場所に名前を入力して <kbd>Return</kbd>（<kbd>Enter</kbd>）を押します。`docs/notes.md` のような名前は途中のフォルダも作り、新しいファイルはビューアで開きます。削除は先に確認され、ゴミ箱に移されます。移せるゴミ箱のないリモートホストでは、完全に削除されます。

その下の **フィルタ** 欄は、閉じたフォルダも含めてフォルダ全体からファイルとフォルダを名前で探し、それらを含むフォルダの中に表示します。スラッシュを入力すると、`src/main` のようにパスで探します。`node_modules` など git が無視するフォルダは、名前では見つかりますが、中は検索しません。<kbd>↓</kbd> か <kbd>Return</kbd>（<kbd>Enter</kbd>）で最初に見つかったファイルを開き、<kbd>Esc</kbd> でフィルタを消去します。

ファイルのメニューからは、専用のエディタペインで開いたり、履歴を表示したりもできます。フォルダのメニューからは、そこでターミナルを開けます。どちらも、エディタで開く、Windows ではほかのアプリで開く、エクスプローラーや Finder で表示する、パスやワークツリーからの相対パスをコピーすることができます。ファイルをペインにドラッグすると、その横か、エディタペインの代わりにエディタペインで開きます。エディタは `editor` 設定（`code` や `zed` など）、未設定ならシステムがそのファイルを開くアプリです。

## 編集

ファイルタブから開いたファイル、エディタペインのファイル、変更タブの差分の新しい側は、VS Code や Zed と同じように編集できます。<kbd>⌘</kbd> <kbd>S</kbd>（<kbd>Ctrl</kbd> <kbd>S</kbd>）で、改行コードを保ったまま今いるファイルを保存します。保存するまでは、ビューアの <kbd>×</kbd> と差分のファイル名の横に点が表示されます。ビューアを閉じるときや別のファイルを開くときは、先に変更を保存するか確認されます。Kero を終了するときは確認されず、次に開いたときに、保存していない変更がそのファイルとともに未保存のまま戻ります。

変更していないファイルは、ディスク上の変更に追従します。変更した後は自分の版が残り、その間にエージェントや別のプログラムがファイルを変更していた場合は、保存するときに上書きするか、変更を破棄して今のファイルを表示するかを確認されます。

## ファイルへ移動

**セッション › ファイルへ移動…**（<kbd>⌘</kbd> <kbd>⇧</kbd> <kbd>N</kbd>、Windows と Linux では <kbd>Ctrl</kbd> <kbd>Shift</kbd> <kbd>N</kbd>）は、今いるペインのワークツリーのファイルを、名前の文字を順に入力して探します: `usvc` で `user_service.go` が見つかります。名前の一致が先で、パスの一致はその後に並びます。スラッシュを入力すると、`src/main` のようにパスだけで探します。<kbd>Return</kbd>（<kbd>Enter</kbd>）で、ファイルタブでクリックしたときと同じようにビューアで開き、<kbd>⌘</kbd> <kbd>↩</kbd>（<kbd>Ctrl</kbd> <kbd>Enter</kbd>）では専用のエディタペインで開きます。リポジトリでは、git が追跡しているファイルと、これから追跡するファイルを一覧するので、`node_modules` など `.gitignore` に書かれたものは含まれません。

## 検索

ファイルタブの検索ボタン、または <kbd>⌥</kbd> <kbd>⌘</kbd> <kbd>F</kbd>（Windows と Linux では <kbd>Ctrl</kbd> <kbd>Shift</kbd> <kbd>S</kbd>）で、ファイルタブに表示されるファイルのテキストを、それらがあるホスト上で、右サイドバーで検索します。入力が止まると検索が始まり、大文字と小文字は区別しません。ファイルが変わったときは、<kbd>Return</kbd>（<kbd>Enter</kbd>）でもう一度検索します。欄の隣のボタンは、**大文字と小文字を区別**、**単語単位で検索**、**正規表現を使う** で、正規表現は Go の構文で書きます。

見つかった行は、そのファイルの下に一覧され、見つかったテキストがハイライトされます。ファイルをクリックすると折りたたみ、行をクリックすると、そのファイルをその行でエディタペインに開きます。すでにそのファイルを表示しているエディタペインがあれば、そこで開きます。ファイルや行を右クリックすると、エディタやエディタペインで開けます。ペインにドラッグすると、そこでその行に開きます。git が無視するファイル、バイナリファイル、2 MB を超えるファイルは検索されず、検索結果には最初の 2,000 行が表示されます。

## コマンドラインから

エージェントが作業内容を見せるように、`kero do` でこれらを表示できます。**設定 › エージェント** の **リモート操作** が必要です:

```sh
kero do files.show                   # ファイルタブ
kero do files.show path=src/main.go  # このファイルをビューアに、またはこのフォルダを開いた状態
kero do search.show query=TODO       # 検索で TODO を検索した状態
kero split --file src/main.go        # ファイルのエディタペイン
```
