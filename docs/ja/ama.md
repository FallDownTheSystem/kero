# Ama

Ama は Kero を代わりに操作してくれるエージェントです。名前はニホンアマガエル（雨蛙、*amagaeru*）から来ています。セッションサイドバー下部のカエルをクリックするか、**Ctrl+Shift+A**（macOS では **⇧⌘A**）を押すか、**表示 › Ama** を選び、たとえば次のように頼みます:

- 「プロジェクト X のオープンな PR すべてにコードレビューを始めて」
- 「古いワークツリーを全部片付けて」
- 「このフォルダの新しいプロジェクトを追加して、この目標でオーケストレーターを始めて」
- 「どのセッションが私を待ってる？」
- 「プロジェクト Y の終わったセッションを全部閉じて」
- 「新しいワークツリーでセットアップスクリプトを実行するには？」

Ama は本物のターミナルで動く普通のエージェントセッションです。デフォルトのエージェント、または **設定 › エージェント › Ama** で選んだエージェント（`ama-agent`）を実行します。プロジェクトの作業は自分では行わず、実際の作業には適切なプロジェクトでセッションか[オーケストレーター](./orchestrators.md)を始めます。どのプロジェクトにも属さず、Ama は 1 つだけです。サイドバーには表示されず、「対応が必要」にも数えられず、通知も送りません。Ama が応答を待っている間はカエルにドットが付きます。

Ama は [Kero を管理する](./cli.md#managing-kero) のコマンドで Kero を管理し、作業中のセッションを閉じることや変更のあるワークツリーを削除することのように、取り消せない操作の前には確認します。

## ウインドウ

Ama は Kero のウインドウの上に、専用のウインドウで開きます。ヘッダーをドラッグすると別のディスプレイにも移動でき、端をドラッグするとサイズを変えられます。Kero はそのサイズと、Kero のウインドウに対する位置を覚えます。Kero のウインドウを移動やリサイズするとそれに付いていき、Kero のウインドウが画面の端に寄ったりディスプレイが外れたりしても、ディスプレイ内にとどまります。サイズと位置は DIP で保存されるので、拡大率の違うディスプレイの間でも同じ大きさのままです。ウインドウを閉じても Ama は動き続け、次に開くと同じ会話に戻ります。ヘッダーでは:

- **新しいチャット**で新しい会話を始めます。
- **履歴**で Ama の過去の会話に戻ります。
- **クリア**で画面を消去します。

ウインドウを最初のサイズでカエルの上に戻すには、カエルを右クリックして **ウインドウの位置をリセット** を選ぶか、**設定 › エージェント › Ama** の **リセット** をクリックします。

Ama の文字はターミナルより 1 ポイント小さくなります（**設定 › エージェント › Ama** の **文字サイズ**、`ama-font-size`。`0` は自動）。Ama のウインドウでは Claude Code のステータスラインを隠します（`ama-hide-status-line`、デフォルトでオン）。Kero は Ama のフォルダの `.claude/settings.json` に空のステータスラインを書き、あなた自身の Claude Code の設定には触れません。Claude Code には、フックまで止めずにステータスラインを完全に消す設定がないため、その場所には空行が 1 行残ります。そのファイルにあなた自身のステータスラインがあれば Kero はそのままにし、隣の `.claude/settings.local.json` はどちらよりも優先されます。

## フォルダ

Ama は、Kero の設定ファイルの隣にある専用フォルダ `ama`（`~/.config/kero/ama`、または `kero config path` が示す場所）で動きます。Ama が起動する前に、Kero はそこに次のファイルを書きます:

| ファイル | 内容 |
| --- | --- |
| `CLAUDE.md`、`AGENTS.md` | Ama への指示: 役割プロンプトと Kero のドキュメントの一覧。Kero の更新時と、役割プロンプトを変えたときに書き直されます |
| `USER.md` | あなた自身の Ama への指示。Kero が一度だけ作り、以後変更しません |
| `docs/` | Kero のドキュメント（このサイトのページ）で、この Kero のバージョンのもの。Kero の更新時に書き直されます |
| `.claude/settings.json` | `ama-hide-status-line` がオンの間の、空のステータスライン |

## Ama が知っていること

Ama は 3 つのところから Kero を学びます:

- **役割プロンプト**（`CLAUDE.md` と `AGENTS.md`）: Ama の役目、実行するコマンド、守るルール。
- **Kero のドキュメント**（フォルダの `docs/`）: お使いの Kero のバージョンのこのサイトのページで、英語です。指示には各ページとその内容が並び、Ama は推測したり Kero のプログラムを探したりせず、質問に関わるページを読んでから答えるよう指示されています。
- **Kero のスキル**: Ama が起動する前に、Kero は `kero skill setup` と同じように Ama のエージェントへスキルをインストールします。それと `kero help` で、すべてのコマンドとオプションがわかります。

そのため Ama は、設定の働きやボタンの場所といった Kero についての質問に、お使いのバージョンのドキュメントをもとに答えます。

## あなたの指示

Kero は Ama の指示をフォルダに `CLAUDE.md` と `AGENTS.md` として書き、Kero の更新時に書き直します。中身は Kero の Ama 用役割プロンプトで、**設定 › エージェント › Ama › 役割プロンプト**（`ama-prompt`）で置き換えられます。**デフォルトに戻す** で Kero のものに戻ります。Ama のエージェントは次のチャットからそれを読みます。自分のプロンプトが置き換えるのは Kero の役割プロンプトだけで、その後ろにはドキュメントの一覧が引き続き付きます。

役割プロンプトに加えるあなた自身の指示は、隣の `USER.md` に書きます。たとえば、レビューにどのエージェントを使うか、短い名前で指すプロジェクト、閉じる前に何を確認してほしいかなどです。このファイルは Kero が一度だけ作り、以後変更しません。Ama はこれを先に読みます。**設定 › エージェント › Ama** から開けます。

**引数**（`ama-agent-args`）は `--model sonnet` のように Ama のエージェントのコマンドの後ろに付くので、Ama 用に別のエージェントを追加する必要はありません。Kero は Ama の開始時と再開時にそれを付けます。

<a id="without-remote-control"></a>

## リモート操作なしで

Ama には[リモート操作](./agents.md#remote-control)は不要です。kerod は Ama のペインにだけ秘密の値 `$KERO_AMA` を渡します。これは Ama のセッションを、kerod が起動するたびに作り直す鍵でハッシュしたものです。`kero do`、`kero focus`、`kero browser` はこれを渡し、kerod がそれを Ama のものと確かめたときだけ、アプリはリモート操作なしで操作を実行します。ファイルには保存されず、他のペインには渡されず、他のマシンの kerod には意味がないため、他のエージェントについては引き続きリモート操作の設定で決まります。
