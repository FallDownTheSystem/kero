# ウインドウ

Kero のウインドウは、左から右に 3 つの部分でできています: **セッションのサイドバー**、今いるセッションの**ペイン**、そして**右サイドバー**です。右サイドバーがファイルやプルリクエストを表示しているときは、その横に**ビューア**が出ます。`sessions-sidebar = right` のときは、セッションのサイドバーが右に、右サイドバーとビューアが左に置かれます。

## セッションのサイドバー

セッションのサイドバーには、あなたの[プロジェクト](./sessions.md#projects)が、それぞれのセッションを下に並べて一覧されます。**サイドバーの切り替え**（<kbd>⌘</kbd> <kbd>B</kbd>、Windows と Linux では <kbd>Ctrl</kbd> <kbd>Shift</kbd> <kbd>B</kbd>）で表示・非表示を切り替えます。

- **プロジェクトの見出し**には、名前、セッションの数（`sidebar-session-count`）、[新規セッションのダイアログ](./sessions.md#new-session-dialog)を開く **+** があります。そのメニューでは、セッションの開始、ワークツリーでのセッションの開始、プロジェクトの移動と削除ができます。見出しをドラッグすると、プロジェクトを並べ替えられます。
- **セッションの行**には、状態のアイコンと名前があります。`sidebar-rows = detailed` では 2 行目に状態のメッセージが、なければブランチと変更が表示されます。[ワークツリー](./worktrees.md)のように自分のブランチにいるセッションには、そのブランチ名が表示されます。[オーケストレーター](./orchestrators.md)には印が付き、その子は ↳ 付きで下に並びます。プルリクエストのレビューは、`#42 Fix the login redirect` のようにプルリクエストの番号とタイトルを名前にし、行の右側に **レビュー** の印が付きます。セッションにポインタを合わせると、ブランチ、アップストリームとの差（先行・遅れ）、プルリクエストのチェックがわかります。メニュー（右クリック）では、名前の変更、終了後の再起動、既読にする、別のプロジェクトへの移動、ID やフォルダのコピー、ファイルマネージャーでのフォルダの表示、プルリクエストの表示やリンク解除、オーケストレーターにする、閉じる、ができます。
- `session-history` がオンのときは、**終了済み** と **アーカイブ** に、エージェントの終了した会話が一覧され、再開できます（[過去の会話](./sessions.md#past-conversations)）。

下部には:

- **プロジェクトを開く**、**セッションへ移動**（[コマンドパレット](./shortcuts.md#the-command-palette)）、**設定**、**メニュー**（⋯）。メニューバーのない Windows と Linux では、メニューバーのメニューは **メニュー** にあります。
- 右側に、対応が必要なセッション、作業中のセッション、終わってまだ見ていないセッションの数。クリックすると、次のそのようなセッションに移動します。kerod に接続できない間は、代わりに **接続中…** か **kerod に接続できません** と表示されます（[トラブルシューティング](./troubleshooting.md#restarting-kerod)）。
- Kero がアップデートされ、kerod がまだ古いバージョンで動いているときの再起動ボタン: バックグラウンドサービスを再起動し、セッションもそれとともに元の場所で再開します。
- [Ama](./ama.md) を開くカエル。Ama が応答を待っている間はドットが付き、メニューには **ウインドウの位置をリセット** があります。

## ペイン

ウインドウの中央は今いるセッションです: その[ペイン](./panes.md)（ターミナル、エディタペイン、ブラウザペイン）が、横か縦に並びます。各ペインのタイトルには、フォルダ（`pane-folder`）と、ブランチとその変更で追加・削除された行数が `fix-login +40 −2` のように表示されます。ペインのブランチをクリックすると、その[変更](./changes.md)を表示します。今いないペインは薄くなります（`dim-unfocused-terminals`）。

## 右サイドバー

右サイドバーには 4 つのタブがあります:

| タブ | 表示するもの | ページ |
| --- | --- | --- |
| **ファイル** | ペインのワークツリーのファイルと、そのテキストの **検索** | [ファイルと検索](./files.md) |
| **変更** | 直前のターン、未コミット、ブランチの変更。ステージとコミット、ブランチとスタッシュ | [変更](./changes.md#changes) |
| **履歴** | コミットのグラフ、スタッシュ、リポジトリのワークツリー | [変更](./changes.md#history) |
| **レビュー** | リポジトリのオープンなプルリクエストと、それをレビューするエージェント | [プルリクエスト](./pull-requests.md) |

ウインドウ右上のボタンで表示・非表示を切り替えるか、ショートカットでタブを開きます（[キーボードショートカット](./shortcuts.md#view)）。端をドラッグすると幅を変えられます。非表示ボタンの横の **サイドバーを拡大** でペインの場所いっぱいに広げ、**すべてのペインを表示** で戻ります。ペインの横に置くには狭すぎるウインドウでは自動で隠れ、ウインドウを広げると戻ります。

## ビューア

ファイル、変更、検索でクリックしたファイルと、レビューでクリックしたプルリクエストは、ペインの横のカード、ビューアで開きます: 読んで編集するファイル、その差分、またはプルリクエストのページです。<kbd>×</kbd> で閉じ、<kbd>Esc</kbd> でペインに戻ります。**ビューアを拡大** でペインの場所いっぱいに広げ、**ペインで開く** でファイルを専用のエディタペインに移します。

## カードと通知

- 右下のカードが、新しいワークツリーの[準備](./worktrees.md#where-worktrees-go-and-what-they-start-from)の進み具合を **キャンセル** とともに示します。
- 操作のエラーのような短いメッセージは、ウインドウの上に少しの間表示されます。
- [通知](./status.md#notifications)はシステムの通知です: セッションが対応を必要とするとき、エージェントが終わったとき、プログラムが失敗したとき、プルリクエストがあなたのレビューを依頼したときに届きます。

## Ama のウインドウ

[Ama](./ama.md) は、カエルから、または <kbd>Ctrl</kbd> <kbd>Shift</kbd> <kbd>A</kbd>（macOS では <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>A</kbd>）で、Kero のウインドウの上に専用のウインドウで開きます。ヘッダーには **新しいチャット**、過去のチャットの削除もできる **履歴**、**閉じる** があります。

## Kero のアイコン

Windows と Linux の通知領域、macOS のメニューバー（`macos-show-app-icon`）にある Kero のアイコンは、ウインドウを閉じても Kero を動かし続けます。そのメニューでは、Kero を開く、[クイックターミナル](./shortcuts.md#quick-terminal)を開く、コンピュータをスリープさせない（`keep-computer-awake`）、設定を開く、アップデートを確認する、終了する、ができます: **終了** はセッションを kerod の中で動かしたままにし、**終了してすべてのセッションを終える…** はセッションを終えます。

## 設定

**設定…**（<kbd>⌘</kbd> <kbd>,</kbd>、<kbd>Ctrl</kbd> <kbd>,</kbd>）で設定ウインドウを開きます。その検索欄で、設定を名前やキーで探せます。各ページは[設定ファイル](./configuration.md)のキーを書きます:

| ページ | 設定するもの |
| --- | --- |
| **一般** | 新しいセッションを始める場所と名前の付け方、サイドバーの行、セッションを閉じることと復元すること、ログイン時に Kero を開くこと、コンピュータをスリープさせないこと、アップデート |
| **外観** | ライトかダーク、言語、テーマとその色、アプリのフォント、セッションのサイドバーを置く側、今いないものを薄くすること |
| **ターミナル** | ターミナルのフォントとそのサイズ、太さ、機能、行の高さ、カーソル、コピーとマウス |
| **ファイル** | エディタ、ファイルタブのドットファイル、コードの色 |
| **Git** | git の状態、差分、ブランチの切り替え、ワークツリーとその[整理](./worktrees.md#cleaning-up-worktrees)、コミットメッセージ、プルリクエスト: 通知、見守り、プロンプト |
| **シェル** | 新しいペインのシェル、その環境、保持するスクロールバック |
| **ブラウザ** | 広告ブロック、DevTools のポート |
| **通知** | 通知するもの、サウンド、Dock のバッジ |
| **キーボード** | 割り当てを変えるためのすべてのショートカット |
| **エージェント** | エージェント向けの Kero のスキル、エージェントとデフォルトのエージェント、[オーケストレーター](./orchestrators.md)、[Ama](./ama.md)、再開コマンド、リモート操作 |
| **ホスト** | [リモートホスト](./remote.md)と、ほかのマシンからこのマシンへの接続の許可 |
| **詳細** | 設定ファイル、バックグラウンドサービス（**再起動**）、ログ、データフォルダ、**すべての設定をリセット** |
